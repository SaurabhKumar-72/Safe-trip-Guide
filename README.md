# SafeTrip Guide

SafeTrip Guide is a lightweight, zero-login web utility designed to help travelers in India avoid street scams and transit overcharging. 

It fetches quick city information using the Wikipedia API and displays location-specific warnings for touts, fake guides, and traps. It also features a realistic fare calculator in Indian Rupees (₹) for autos, cabs, and bike taxis. Built simply using HTML5, CSS3, and JavaScript.
